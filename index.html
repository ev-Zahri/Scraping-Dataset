CARA KERJA EKSTENSI // EXTENSION TUTORIAL EDGE & CHROME

Panduan Menggunakan Browser Extension

Ekstensi browser ini membaca streaming data langsung dari tab aktif tanpa perlu login API resmi. Ikuti 4 langkah mudah untuk mulai scraping:

LANGKAH 01 install_desktop

Pasang Ekstensi

Buka edge://extensions atau chrome://extensions. Aktifkan Developer Mode, klik Load Unpacked, lalu pilih folder extension.

LANGKAH 02 tab

Buka Tab Target

Buka halaman yang ingin Anda scrape di tab aktif (misal: pencarian tweet x.com/search, video YouTube, atau feed Threads).

LANGKAH 03 radar

Scan / Auto Scroll

Buka popup ekstensi dari toolbar browser. Pilih platform, lalu klik "Scan Halaman Saat Ini" (ekstraksi instan) atau jalankan "Auto Scroll" untuk stream berkala.

LANGKAH 04 file_download

Unduh & Drag ke Sini

Klik tombol Export JSON di popup (atau simpan HTML halaman via Ctrl+S), kemudian tarik berkas tersebut ke workspace di bawah.
